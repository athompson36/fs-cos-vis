# Beta 0.1a Release Runbook

## Goal
Ship signed/notarized beta artifacts for `CosmicVisualizer beta 0.1a` and keep Sparkle-compatible update metadata current.

## Release workflow

1. Tag release branch with `v0.1a*`.
2. Run `.github/workflows/release-macos-beta.yml`.
3. Workflow builds release app, packages ZIP/DMG, uploads artifacts.
4. Publish artifacts to GitHub Release.
5. Update Sparkle appcast feed to reference the latest signed archive.

## Required secrets and signing setup

- Apple signing certificate and private key
- Apple notarization credentials
- Optional Sparkle signing key

## Installer artifacts

- `CosmicVisualizer-<tag>.zip`
- `CosmicVisualizer-<tag>.dmg`

Generated by `scripts/release/package-beta.sh`.

## Post-install validation checklist (audio permissions)

1. Launch the installed build and open the Setup Wizard `audio` step (or `Settings > Audio input and OBS forwarding`).
2. Confirm microphone permission prompt appears on first audio start.
3. If macOS shows denied/restricted state (common when switching local debug/release builds), click **Open Microphone Settings** in-app and enable access.
4. Return to the app and click **Retry audio start** (wizard) or re-open Live Show to verify audio metrics update.

## Notes

- Keep version metadata synchronized with `project.yml`.
- Use Settings -> App updates to validate update checks in a local beta build.

# Beta 0.1a Release Runbook

## Goal
Ship beta artifacts for `CosmicVisualizer beta 0.1a` and keep Sparkle-compatible update metadata current when signing is available.

**Technical detail (CI vs signing, notarization, Sparkle keys):** [`release-runbook.md`](release-runbook.md).

## Release workflow

1. Tag release branch with `v0.1a*`.
2. Run `.github/workflows/release-macos-beta.yml` (or let it trigger on the tag).
3. Workflow builds **Release** app, packages **unsigned** ZIP/DMG, uploads artifacts.
4. For tester handoff: **sign + notarize** the app (maintainer step; see [`release-runbook.md`](release-runbook.md)), then publish DMG/ZIP to GitHub Release.
5. Update Sparkle **appcast** to reference the latest **signed** ZIP when using auto-updates.

## Required secrets and signing setup

CI does **not** sign or notarize yet. For production builds you need (locally or future CI secrets):

- Apple **Developer ID Application** certificate and private key  
- **Notarization** credentials (`notarytool` profile or API key)  
- Optional Sparkle **edDSA** private key for signing updates (never commit)

## Installer artifacts

- `CosmicVisualizer-<tag>.zip`
- `CosmicVisualizer-<tag>.dmg`

Generated by `scripts/release/package-beta.sh`.

## Post-install validation checklist (audio permissions)

1. Launch the installed build and open the Setup Wizard `audio` step (or `Settings > Audio input and OBS forwarding`).
2. Confirm microphone permission prompt appears on first audio start.
3. If macOS shows denied/restricted state (common when switching local debug/release builds), click **Open Microphone Settings** in-app and enable access.
4. Return to the app and click **Retry audio start** (wizard) or re-open Live Show to verify audio metrics update.

## Post-install validation checklist (OSC control)

1. In Setup Wizard `output` step (or `Settings > Remote control`), enable **OSC UDP control**.
2. Set OSC port/token for your LAN policy.
3. From repo root, run:
   - `scripts/osc/send.sh "/cosmic/scene/next"`
   - `scripts/osc/query-state.sh`
4. Confirm command execution and state response; if no response, verify bind mode, host/port, and token alignment.

## Post-install validation checklist (remote recording controls)

1. Open Setup Wizard `output` step and verify recorder remote command hints are visible.
2. Trigger recording start/stop from OSC:
   - `scripts/osc/send.sh "/cosmic/recording/start"`
   - wait ~2 seconds
   - `scripts/osc/send.sh "/cosmic/recording/stop"`
3. Query state and verify recorder fields populate:
   - `scripts/osc/query-state.sh`
   - check `liveOutputRecording`, `liveOutputRecordingStatus`, and `liveOutputLastRecordingPath` in the returned JSON.
4. Confirm recorded media exists under project-local `Media/Recordings` when a show project folder is active.

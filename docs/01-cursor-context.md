# Detailed Cursor Context

## Primary product promise

Create a visual instrument that feels musical, immersive, and alive. The app must react in a way that feels synchronized, not random.

## Core experience

A user should be able to:
- choose an audio device
- see incoming signal activity
- load a scene
- switch scenes with previous/next
- toggle liquid light
- apply image overlays
- change themes and palettes
- go fullscreen and use it live

## Main user personas

### Live performer / visual operator
Needs fast switching, fullscreen reliability, and strong reactive behavior.

### Studio creator
Needs a beautiful, slow-moving, controllable ambience tool.

### Brand / art user
Needs overlays, themes, and scene presets for identity-driven visuals.

## Product values

- musical responsiveness
- visual richness
- artistic identity
- reliability in live use
- modular architecture

## Phase 1 MVP

Must include:
- audio device selection
- live FFT feature extraction
- BPM detection
- one fractal family
- one liquid-light family
- one hybrid compositor
- previous / next scene controls
- imported image overlay support
- palette selection
- fullscreen mode

## Phase 1 quality bar

Even MVP should feel premium:
- smooth motion
- strong glow hierarchy
- legible controls
- scene switching without jarring resets
- no generic placeholder styling where avoidable

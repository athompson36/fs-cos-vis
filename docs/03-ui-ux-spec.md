# UI / UX Spec

## Primary screens

### 1. Performance View
Primary live-use screen.

Required controls:
- audio device selector
- input meter
- BPM readout
- beat indicator
- previous button
- next button
- random scene button
- fullscreen button
- quick palette strip
- liquid light toggle

### 2. Scene Editor
Used to adjust selected scene.

Sections:
- fractal controls
- liquid-light controls
- overlay controls
- blend controls
- animation controls
- audio mapping controls

### 3. Theme / Palette Browser
Used to switch complete color systems quickly.

### 4. Overlay Manager
Used to import and configure image layers.

## Interaction priorities

- previous/next should work instantly
- fullscreen should be one tap away
- performance mode should stay readable in low light
- controls should feel tactile and glowy, not flat

## UI style notes

Use a premium cosmic control-panel feel:
- translucent surfaces
- soft bloom accents
- rounded controls
- layered contrast
- not overly busy

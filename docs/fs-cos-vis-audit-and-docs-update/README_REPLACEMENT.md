# FS-COS-VIS
## FS DMX Vision Beta Application

FS-COS-VIS is a hybrid macOS performance application that combines:
- real-time cosmic audio-reactive visualization
- fractal + liquid-light scene authoring
- live performance controls
- lighting patch/cue/modulation/stage workflows
- verification and transport scaffolding
- beta distribution/update support

## Current product state

This repository is no longer a starter scaffold.
It is a late-stage beta application with substantial implementation across:
- rendering
- audio/BPM systems
- scene workflows
- live output/recording
- web/MIDI/OSC control
- lighting and stage planning
- fixture verification
- project packaging and beta operations

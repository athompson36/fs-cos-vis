# Drew Spaceman Aesthetic Guide

## Purpose

This document tells Cursor how to preserve the correct visual soul of the app.

## Core identity

Drew Spaceman is not generic sci-fi.
It is a specific blend of:
- cosmic wonder
- psychedelic glow
- analog liquid-light energy
- surreal desert-midnight mysticism
- musical performance atmosphere
- dreamy but grounded visual drama

## Emotional targets

The app should feel:
- immersive
- hypnotic
- luminous
- expressive
- alive
- a little mystical
- artful rather than purely technical

## Visual ingredients

- deep blacks and midnight blues
- magentas, violets, cyan glows, solar gold, acid pink accents
- nebula haze
- lens bloom
- haloed silhouettes
- liquid refractions
- layered transparency
- rich gradients with depth

## Texture direction

Prefer textures that feel like:
- cosmic dust
- oil-and-water light projection
- glass haze
- analog projection glow
- celestial fog
- prismatic drift

Avoid textures that feel like:
- sterile flat UI panels
- generic game HUD chrome
- hard-edged cyberpunk only
- corporate dashboard minimalism

## Motion direction

Motion should feel musical and fluid:
- drifting
- pulsing
- breathing
- swelling
- blooming
- spiraling

Avoid motion that feels:
- twitchy without purpose
- random for randomness' sake
- overly mechanical

## Fractal direction

Fractals should feel cinematic and spiritual rather than purely mathematical.
The best modes will look like:
- portals
- nebula cathedrals
- stained-glass galaxies
- living mandalas
- cosmic tunnels

## Liquid-light direction

The 60s liquid-light mode should feel inspired by classic projector-era psychedelic visuals:
- thick color blobs
- translucent overlap
- slow thermal drift
- magnified edges
- organic color bleeding

## UI direction

The UI can be modern, but the atmosphere must still support the universe:
- glassy surfaces
- subtle glow
- deep-space contrast
- tasteful cosmic polish
- premium performance-tool seriousness

## One-sentence style checkpoint

If a screen looks like a generic VJ app or a plain developer prototype, it is too far away from the Drew Spaceman aesthetic.

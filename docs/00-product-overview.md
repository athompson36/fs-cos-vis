# Product Overview

## Working title

Cosmic Visualizer

## What it is

A real-time audio-reactive visual performance app for macOS that generates fractal visuals, liquid-light effects, and blended cosmic scenes from live audio.

## What makes it special

This app is not only reactive to amplitude and FFT bands. It also uses detected BPM and beat pulse information to drive scene speed, transitions, blooming, zoom behavior, pulsing, blob motion, and timing-sensitive effects.

## Main feature groups

### Audio system
- audio device selection
- live input monitoring
- FFT analysis
- BPM estimation
- beat/transient detection
- response smoothing

### Visual system
- fractal scenes
- liquid-light scenes
- hybrid scenes
- particles / glow / post FX
- image overlays
- palette and theme presets

### Performance system
- previous / next scene controls
- scene browser
- fullscreen output
- external display support
- quick theme switching
- preset save/load

## Example use cases

- live music projection
- psychedelic stage backdrop
- studio ambience generator
- branded logo visualization
- content creation / streaming background
- gallery / installation display
